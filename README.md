# J&J Imprint Co. — Website

Static site for GitHub Pages. Brand: black / gold / blush / cream, Cinzel + Jost + Allura.

## Pages
- index.html — home
- services.html — full service menu with pricing
- storefront-branding.html — featured storefront branding landing page
- order.html — Start Your Order, category-based Formspree forms
- faq.html — policies (design, proofs, payment, turnaround)
- contact.html — general contact form
- portfolio.html — recent work / photo placeholders

## Before going live
1. Replace every `YOUR_..._FORM_ID` in order.html and contact.html with your real Formspree endpoint per category.
2. Enable file uploads on each Formspree form, then add `<input type="file" name="attachment">` where marked in order.html.
3. Swap the `.ph` placeholder blocks for real photos across all pages.
4. Fill in real phone number on contact.html.
